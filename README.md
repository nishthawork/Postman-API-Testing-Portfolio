# Postman API Testing Portfolio

## Project Overview
This project demonstrates practical API testing using Postman and Newman.

## API Details
- API: DummyJSON Login API
- Method: POST
- Endpoint: https://dummyjson.com/auth/login

## Testing Scenarios
1. Login with valid credentials
2. Login with invalid password
3. Login with blank username
4. Login with blank password
5. Login with invalid username

## Testing Validations
- HTTP status code validation
- Response JSON validation
- Access token validation
- Username validation
- Error message validation
- Negative scenario validation

## Data-Driven Testing
Executed 5 test scenarios using CSV test data with Newman.

## Tools Used
- Postman
- Newman
- Newman HTML Extra Reporter
- CSV

## Test Execution Report
See `Login_API_Report_Safe.html` for the HTML execution report.

## Test Data Information
Public DummyJSON demo credentials are used for testing purposes only. No personal credentials are included.
